# BF-006-1: 界面全中文化 + 区域/任务信息面板

> **状态**: 已修复
> **发现**: 2026-07-29
> **修复**: 2026-07-29
> **关联**: RFC-006（NPC对话）前置体验优化

## 描述

两个体验问题：

1. **界面未中文化**：标题、提示文本、按钮、占位符全是英文。除了内部 id 可保留英文，面向用户的一切文本应为中文。
2. **缺少区域和任务信息**：右侧面板只显示 NPC，没有当前区域详情（名称/描述/可前往区域）和玩家任务列表。玩家无法从 UI 了解自己所处环境。

## 修改计划

### 1. 全中文化

**GameSetup.tsx**：
- 标题 `Talking Legend` → `传说之语`
- 副标题 → `言语即是力量。踏入这个世界，成为不朽传奇。`
- 标签 → `勇者，请留下你的名字：`
- 占位符 → `输入姓名…`
- 按钮 → `开启传奇`
- 加载中 → `命运之轮转动中…`

**GameScreen.tsx**：
- 开场白 → 中文化
- 面板标题 → `附近人物` → `附近人物`
- 输入框占位符 → `你想做什么？`
- 按钮 → `行动`
- 加载提示已有中文（`命运之轮转动中…`）
- 时间/天气 → `清晨`/`晴朗`（映射中文）
- 区域名 → 从 world.json 中文名映射

### 2. 区域+任务面板

右侧面板改为两个区块：

```
┌─────────────────┐
│ 📍 当前位置      │
│ 石辉村           │
│ 宁静的山谷聚落    │
│                  │
│ 🌍 可前往        │
│ · 低语森林       │
│ · 龙脊峰         │
├─────────────────┤
│ 📋 任务          │
│ (暂无)           │
├─────────────────┤
│ 👥 附近人物      │
│ · 长老 Marin     │
│ · 游侠 Kael      │
└─────────────────┘
```

数据来源：
- 区域名称/描述 → `gameState.world.regions[].name` + `.description`
- 可前往区域 → `gameState.world.regions` 中 `connectedRegions` 含 `currentRegion` 的
- 任务 → `gameState.player.quests[].title` + `.status`

### 涉及文件

- `frontend/src/components/GameSetup.tsx`
- `frontend/src/components/GameScreen.tsx`

## 修改后结果

### 做了什么

**GameSetup.tsx** — 全中文化：
- 标题 `Talking Legend` → `传说之语`
- 副标题 → `言语即是力量。你的话语将塑造这个世界…`
- 标签 → `勇者，请留下你的名字：`
- 占位符 → `输入姓名…`
- 按钮 → `开启传奇` / 加载中 → `命运之轮转动中…`

**GameScreen.tsx** — 全中文化 + 区域任务面板：
- 所有 UI 文本转为中文
- 新增区域名中文映射（village→石辉村, forest→低语森林, lake→镜湖, mountains→龙脊峰）
- 新增天气/时间中文映射
- 右侧面板改为 4 区块：
  1. 📍 当前位置：区域名 + 描述
  2. 🌍 可前往：相连区域列表
  3. 📋 任务：玩家任务（进行中/已完成/失败）+ 状态标签
  4. 👥 附近人物：同区域 NPC
- 面板宽度 260px，独立 scroll
