# RFC-008: 世界自主演化系统

> **状态**: 已提议
> **优先级**: P1
> **创建**: 2026-07-26

## 问题

世界目前是完全静态的：时间不流逝、天气不变化、NPC 情绪不漂移。`GET /api/game/:gameId/world` 直接返回占位串 `[world state coming in RFC-008]`——代码里已标注本 RFC 是债主。

核心痛点：

1. **世界没有生命力**：玩家不操作时世界纹丝不动，破坏「活的世界」幻想
2. **演化需要确定性骨架**：纯靠 LLM 驱动世界演化成本高且不可控——设计决策已定「确定性世界 tick（时间/天气/NPC 情绪漂移）+ haiku 定期过滤可记忆事件」的混合架构
3. **事件沉淀无通路**：tick 产生的事件哪些值得写入 NPC 记忆、哪些只是一阵风，需要过滤机制，否则记忆表会被噪音灌满
4. **区域移动未实现**：MVP 要求支持玩家在 village/forest 两区域移动，移动本身也是世界状态变更的一种

## 动机

世界演化让游戏在两次玩家输入之间依然「活着」，是把静态数据库变成世界的关键一步。确定性 tick 保证可测试、可回放，LLM 只负责价值判断（哪些事值得记住）。
