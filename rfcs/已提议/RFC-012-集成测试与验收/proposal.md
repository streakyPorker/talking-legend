# RFC-012: 集成测试与验收

> **状态**: 已提议
> **优先级**: P3
> **创建**: 2026-07-26

## 问题

各 RFC 独立验收（单测 + 启动 + curl），但全链路从未作为一个整体被验证过：创建游戏 → GM 叙事流 → NPC 对话 → 意图触发事件 → 世界演化 → 剧情推进，这条完整 loop 没有端到端的验收手段。

核心痛点：

1. **局部正确 ≠ 整体可玩**：每个模块单测全绿，拼起来可能处处是缝（契约漂移、时序竞争、SSE 与状态同步）
2. **LLM 链路难以测试**：真实 LLM 调用昂贵且不确定，需要 mock/录制策略做可重复的集成测试
3. **验收无标准**：什么叫「MVP 做完了」需要一份明确的全链路验收清单，对应完工铁律的终局形态

## 动机

MVP 的收官 RFC：定义并执行全链路验收，把十二个 RFC 的成果钉成一个可玩的游戏。P3——等前面的砖都烧好再砌墙验收。
