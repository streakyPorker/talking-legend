# RFC-015: 前端导航栏重构 — 侧边栏改为顶部导航

> **状态**: 已提议
> **优先级**: P1
> **创建**: 2026-07-30

## 当前状态

### 现有布局

当前前端有 3 个页面/组件：

1. **入口页 (GameSetup)** — 居中卡片式，无任何导航栏。右上角有浮动齿轮按钮（配置入口）。
2. **游戏页 (GameScreen)** — 两栏布局：
   - 左侧 **narrative-panel**（主内容区）：叙事流展示 + 行动输入框
   - 右侧 **info-sidebar**（260px 固定宽度侧边栏）：当前位置、可前往区域、任务列表、附近人物
   - 顶部 header：世界名 + 区域/回合/时间/天气 + 齿轮按钮
3. **配置中心 (ConfigScreen)** — Modal 弹窗，独立于页面布局

### 存在的问题

1. **侧边栏占用过多空间**：右侧 260px 固定侧边栏与叙事面板抢空间，在小屏幕上尤其拥挤。当前信息面板的内容量不大，用整个侧边栏承载显得浪费。
2. **信息访问路径割裂**：玩家需要在叙事区和信息面板之间频繁视线切换，参考主流 RPG/策略游戏（如《博德之门3》《神界原罪2》），关键信息应浮动在游戏画面之上或集成到统一顶部栏，而非独占一列。
3. **扩展性差**：RFC-011 (NPC 对话面板) 需要弹出式对话窗口；RFC-007/008（事件/演化）会引入更多信息维度。侧边栏模式会让 UI 进一步碎片化。
4. **不符合现代游戏 UI 习惯**：主流游戏信息展示采用顶部导航/状态栏 + 全屏内容区 + 浮动面板的模式，而非 Web 后台常见的侧边栏布局。

## 期望目标

### 核心理念

**去掉侧边栏，改为纯顶部导航栏模式**。页面布局变更为：

```
┌──────────────────────────────────────────────┐
│  顶部导航栏（世界名 · 区域 · 回合 · 时间 · 天气 · ⚙）  │
├──────────────────────────────────────────────┤
│                                              │
│              全宽内容区                        │
│   （叙事流 + 浮动信息卡片/可折叠面板）              │
│                                              │
├──────────────────────────────────────────────┤
│  底部行动输入栏                                 │
└──────────────────────────────────────────────┘
```

### 具体目标

1. **顶部导航栏**统一承载所有全局信息和操作入口：
   - 世界名称（可点击返回入口页）
   - 当前位置 + 可切换区域（下拉）
   - 回合数 / 时间 / 天气
   - 任务摘要（徽标数字）
   - 附近 NPC 状态指示
   - 配置齿轮按钮

2. **全宽内容区**作为叙事展示区域，去掉右侧侧边栏：
   - 叙事文本占满可用宽度，提升阅读体验
   - 详细信息（区域描述、任务详情、NPC 详情）改为**悬浮卡片/工具提示**或**可折叠内联面板**，按需展示而非常驻

3. **底部行动输入栏**保持不变（当前已合理）

4. **入口页 (GameSetup)** 也统一为顶部导航栏风格（即使只有齿轮按钮），保持视觉一致性

### 范围边界

- **包含**：前端布局重构、导航栏组件开发、信息展示方式调整、CSS/样式体系变更
- **不包含**：后端 API 变更、新功能开发（NPC 对话面板等属于 RFC-011）
- **依赖**：可能与 RFC-010（前端组件化重构）有交叉，需要协调——导航栏本身可能作为 RFC-010 组件化拆分的一部分来实现

## 影响范围

### 需要修改的文件/组件

| 文件 | 改动 |
|------|------|
| `frontend/src/components/GameScreen.tsx` | 去掉 `info-sidebar`，信息集成到顶部导航栏；叙事区改为全宽 |
| `frontend/src/components/GameSetup.tsx` | 统一顶部导航栏风格 |
| `frontend/src/App.tsx` | 可能需要抽取共享导航栏组件 |
| `frontend/src/index.css` | 新增导航栏样式、移除侧边栏样式、调整布局 |
| `frontend/src/components/ConfigScreen.tsx` | 可能无需改动（已是 Modal） |

### 新增组件（预期）

| 组件 | 职责 |
|------|------|
| `TopNavBar` | 顶部导航栏容器，承载所有全局信息 |
| `RegionInfo` | 当前位置/区域切换（下拉或面包屑） |
| `GameStatusBar` | 回合/时间/天气状态指示 |
| `QuestBadge` | 任务数量和状态摘要 |
| `NpcPresenceIndicator` | 附近 NPC 简况指示器 |
| `InfoPopover` / `InfoTooltip` | 悬浮信息卡片通用组件 |

### 不影响

- 后端所有模块
- API 合约
- 配置中心（ConfigScreen 已是 Modal，不受布局影响）
- 已有的功能逻辑（只改 UI 层）
