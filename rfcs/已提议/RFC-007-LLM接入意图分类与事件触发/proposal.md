# RFC-007: LLM 接入 — 意图分类与事件触发

> **状态**: 已提议
> **优先级**: P1
> **创建**: 2026-07-26

## 问题

玩家输入是自由文本（"我问长老关于龙的事"），系统需要理解玩家想干什么才能驱动世界响应。目前没有任何意图理解层。

核心痛点：

1. **关键词匹配走不通**：自由文本的表达方式无穷，硬编码关键词匹配覆盖率极低且脆弱——设计决策已明确用意图路由（intent + entity）替代关键词匹配
2. **事件无法触发**：世界事件（storylines.active_events）的触发条件本质上是「玩家做了某类事」，没有意图分类就没有可靠的事件触发入口
3. **成本敏感**：每次输入都做意图判断，调用频率是全文最高的 LLM 场景，必须用 Haiku 级小模型并控制 prompt 体积
4. **与对话并行**：设计决策要求意图分类与 NPC 对话并行执行，意图结果还要能影响 GM 叙事走向

## 动机

意图分类是连接「自由输入」与「结构化世界响应」的翻译层，是 Haiku 层的核心职责之一，也是 008（世界演化）与 009（事件链）的触发前置。
