# RFC-016: 地域移动系统

> **状态**: 设计中
> **优先级**: P1
> **创建**: 2026-07-30

## 问题

当前游戏世界有多个区域（石辉村、低语森林、镜湖、龙脊峰），区域之间有连接关系（connectedRegions），但玩家无法移动。侧边栏"可前往"区域是纯展示文本，点击无反应；对话中提及"去森林"也不会触发移动。

## 动机

地域移动是开放世界游戏的**核心交互**。没有移动，游戏世界是静态的——玩家被困在起始区域，叙事无法推进到其他场景，NPC 互动受限于当前位置。

## 范围

### 包含
1. **后端 API**：`POST /api/game/:id/move` — 接收目标区域，校验连通性，更新位置 + 生成移动叙事
2. **前端点击移动**：侧边栏"可前往"区域改为可点击，点击后触发移动
3. **对话移动**：玩家在输入框输入"去低语森林"等移动意图 → LLM 识别 → 触发移动

### 不包含
- 移动中的随机遭遇/事件（留给 RFC-008/009）
- 移动动画（当前版本保持简洁）
- 多步路径规划（只支持直接相邻区域移动）

## 影响文件

| 层 | 文件 | 变更 |
|----|------|------|
| Backend | `game.controller.ts` | 新增 `POST /:id/move` |
| Backend | `game.service.ts` | 新增 `moveToRegion()` |
| Backend | `game.schema.ts` | 新增 move 请求 zod schema |
| Frontend | `ConnectedRegions.tsx` | 区域项改为可点击按钮 |
| Frontend | `useGameAction.ts` | 扩展支持 move 类型 |
| Shared | `index.ts` | 新增移动相关类型 |
