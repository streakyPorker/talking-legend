# RFC-010: 前端组件化重构

> **状态**: 已提议
> **优先级**: P2
> **创建**: 2026-07-26

## 问题

前端目前只有三个组件（`App` / `GameSetup` / `GameScreen`），状态靠 React 内置 useState 传递。随着 SSE 流式叙事、NPC 对话面板、世界状态展示加入，单体组件会迅速膨胀失控。

核心痛点：

1. **状态管理缺位**：设计目标栈是 React + Zustand + Tailwind，但 Zustand 和 Tailwind 至今未安装——游戏状态（世界、NPC、叙事流、输入锁定）跨组件共享会越来越痛苦
2. **组件职责不清**：GameScreen 将同时承载叙事流、NPC 面板、世界栏、输入区，违反单一职责
3. **样式体系缺失**：没有 Tailwind，样式散在 index.css，UI 复杂度上来后难以维护
4. **阻塞 011**：SSE 双分区展示与 NPC 对话面板需要组件边界先划清

## 动机

在加新 UI 功能之前先还债：引入 Zustand 状态管理与 Tailwind 样式体系，拆分组件边界。这是 011 的直接前置。
