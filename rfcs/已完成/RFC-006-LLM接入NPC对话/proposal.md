# RFC-006: LLM 接入 — NPC 对话

> **状态**: 已完成
> **优先级**: P1
> **创建**: 2026-07-26

## 问题

与 NPC 自由对话是本游戏区别于传统文字冒险的核心体验，但当前 `POST /api/game/:gameId/npc/:npcId/talk` 是空壳，没有任何 LLM 驱动的对话能力。

核心痛点：

1. **NPC 没有人格**：`npcs` 表存了 personality/mood/memoryOfPlayer，但没有机制把这些注入对话生成，NPC 无法「扮演」自己
2. **记忆不产生价值**：NPC 记忆表（npc_memories）已就绪，但对话中不记得玩家做过什么，记忆写入与读取链路都不存在
3. **对话与世界状态脱节**：NPC 应对同区域事件、时间、天气有感知（设计决策：仅同区域 NPC 可对话），当前无任何关联
4. **并行调度未落地**：设计决策要求 NPC 对话与意图分类并行调用、前端独立分区展示，需要后端支持并行 LLM 编排

## 动机

NPC 对话是 Sonnet 层的主战场，也是「世界因对话而生动」承诺的兑现点。依赖 004 的上下文方案与 003 的世界配置（NPC 定义来源）。
